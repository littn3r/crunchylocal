# Лицензии

[README](../README.ru.md) · [English](LICENSING.md)

Собственный код проекта распространяется под MIT. Сторонний код и шрифты сохраняют свои лицензии; при распространении проекта их уведомления нужно сохранять.

| Материал | Уведомления и исходники |
| --- | --- |
| Shaka Player 4.15.12 и включённый код | `licenses/shaka-player.txt`: полный файл именно этой версии, включая dash.js |
| Material Symbols | `licenses/material-symbols.txt`, Apache-2.0 |
| Liberation Sans 2.00.5 | `licenses/liberation-sans.txt` и `public/libass/OFL.txt`, OFL-1.1 |
| JS/WASM субтитров и библиотеки | `public/libass/LICENSE`, `COPYRIGHT`, `JASSUB-LICENSE`, `EMSCRIPTEN-NOTICES.txt`; [полный комплект исходников и пересборка](../third_party/libass-wasm/README.md) |
| Уведомления каталога | `licenses/catalog.txt`; файл не подтверждает права на все сторонние описания и изображения |
| Собственный код | Корневой [LICENSE](../LICENSE) |

В плеере есть ссылка **«Лицензии и исходники»** с доступом к исходникам субтитров и уведомлениям. Наше изменение JS-обёртки оформлено отдельным патчем. Пользователь может менять LGPL-компонент, пересобирать и заменять worker для своего использования; проект не запрещает обратную разработку, необходимую для отладки этих изменений.
