Вход на телефоне и компьютере

Официальная страница входа откроется здесь через браузер сервера. Нажмите нужное поле на экране и вводите текст. Кнопка «Клавиатура» открывает клавиатуру повторно. Данные ввода проходят через ваш сервер и не сохраняются.

Введите email и пароль. При необходимости проверку можно открыть вручную.

Вводите данные здесь без задержки. Плеер отправит форму в официальный браузер автоматически. Пароль не сохраняется.

Загружаем официальный вход…

Расширение установлено

Нажмите кнопку и введите логин и пароль в открывшейся вкладке Crunchyroll. Если вы уже вошли там, сеанс подключится сразу.

Вход через расширение на компьютере

Оно читает сеанс после входа на официальном сайте и передаёт его только в эту вкладку плеера. Пароль проекту не передаётся.

Скачать для Chrome / Chromium
  1. Распакуйте скачанный ZIP.
  2. Откройте chrome://extensions, включите «Режим разработчика».
  3. Нажмите «Загрузить распакованное расширение» и выберите папку extension.
  4. Обновите эту вкладку.
Установить скрипт Tampermonkey
  1. Установите Tampermonkey в браузере.
  2. Нажмите кнопку установки скрипта и подтвердите добавление.
  3. Откройте общие Settings менеджера: Config mode → Advanced → Security → Allow scripts to access cookies → All.
  4. Обновите эту вкладку.

Для доступа к HttpOnly-cookie документация Tampermonkey требует Beta-версию. Если скрипт не видит сеанс, используйте встроенную форму входа.

Подключить через cookies.txt вручную

Выберите экспортированный файл cookies.txt или вставьте значение etp_rt.

Сеанс хранится в защищённом cookie вашего браузера. На сервере остаётся ключ шифрования.
