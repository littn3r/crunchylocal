# Crunchy Local

**Свой плеер для Crunchyroll — прямо в браузере и с синхронизацией списков аниме.**

[English](README.md) · **Русский**

Crunchy Local — небольшой веб-плеер, который вы запускаете у себя: через Docker на компьютере или домашнем сервере. Открываете в любом браузере и смотрите — отдельное приложение ставить не нужно.

Одно место, где можно посмотреть серию, почитать про тайтл и отметить просмотренное на Shikimori или MyAnimeList — без лишних вкладок.

## Что умеет

- 🔎 **Каталог** — вся библиотека Crunchyroll с поиском и фильтрами.
- 🎬 **Плеер** — выбор языка озвучки, субтитры с оформлением, настраиваемые размер и положение реплик.
- ⏯️ **Продолжение с того же места** — плюс полный экран и мини-плеер.
- 📋 **Синхронизация списков** — подключите Shikimori и/или MyAnimeList, и серии, оценки и статусы будут обновляться сами.
- 📖 **Страницы тайтлов** — описание, студии, жанры, рейтинги и персонажи.
- 🌐 **Русский и английский интерфейс** — при первом запуске язык подхватывается из браузера.

Каталог обновляется сам раз в сутки.

## Что понадобится

- **Аккаунт Crunchyroll с активной подпиской.** Плеер ничего не «открывает» — тайтл должен быть доступен вашему аккаунту в текущем регионе.
- **Docker с Compose:**

| Где запускаете сервер | Что установить |
| --- | --- |
| Windows | Docker Desktop (Linux-контейнеры) |
| macOS | Docker Desktop |
| Linux | Docker Engine + плагин Compose |

## Быстрый старт

**1. Скачайте проект.** Склонируйте репозиторий или нажмите **Code → Download ZIP** и распакуйте архив. Откройте терминал в папке проекта. Если пользуетесь Docker Desktop — запустите его.

**2. Создайте настройки.**

```sh
docker compose -f compose.setup.yaml run --rm setup http://127.0.0.1:8765
```

Команда создаст `.env` и `oauth_apps.json`. Уже существующие файлы она не трогает. Python и Node.js на компьютер ставить не нужно — всё работает внутри Docker.

**3. Запустите плеер.**

```sh
docker compose up -d --build
```

Первая сборка скачивает всё необходимое, так что придётся подождать несколько минут.

**4. Откройте [http://127.0.0.1:8765](http://127.0.0.1:8765)** и войдите в Crunchyroll. Shikimori и MAL — по желанию, их можно подключить в любой момент.

> На Linux, если ID вашего пользователя не 1000, загляните в [настройку прав файлов](docs/SETUP.ru.md#создание-настроек).

## Просмотр с других устройств

Чтобы смотреть с телефона, ТВ-приставки или другого компьютера, браузеру нужен **HTTPS с доверенным сертификатом** — по обычному HTTP на сетевом адресе DRM не заработает. Выберите удобный вариант:

| Вариант | Кому подойдёт |
| --- | --- |
| [Свой домен + Caddy или Nginx](docs/SETUP.ru.md#свой-домен-и-https) | Свой сервер, автоматический или собственный сертификат; Tailscale не нужен |
| [Tailscale Serve](docs/SETUP.ru.md#https-и-tailscale) | Доступ только с ваших устройств в сети Tailscale |

### Через свой домен

1. Направьте домен, например `player.example.com`, на сервер. Для домашнего сервера откройте входящий доступ на роутере, если сайт должен быть виден из интернета.
2. Укажите в `.env`: `CRUNCHY_LOCAL_PUBLIC_ORIGIN=https://player.example.com`.
3. Поднимите HTTPS-прокси на той же машине: `https://player.example.com` → `http://127.0.0.1:8765`.
5. Если подключены Shikimori/MAL, обновите у них Redirect URL. Готово — открывайте сайт на нужном устройстве.

[Готовые примеры для Caddy, Nginx и своего сертификата →](docs/SETUP.ru.md#свой-домен-и-https)

### Через Tailscale

Установите Tailscale на сервер и на устройства, с которых будете смотреть, подключите их к одной сети и включите Tailscale Serve. Затем откройте выданный HTTPS-адрес — [пошаговая инструкция](docs/SETUP.ru.md#https-и-tailscale).

Что полезно помнить:

- Сервер и Docker должны быть включены, пока вы смотрите.
- `127.0.0.1` — это всегда *то устройство, на котором открыт браузер*. С другого устройства используйте HTTPS-адрес сервера.
- HTTPS шифрует соединение, но не решает, **кто** может открыть сайт. Если выставляете плеер в интернет — настройте ограничение доступа на прокси (пароль, список IP).

## Как это устроено

В Docker работают две вещи: сам сайт и скрытый Chromium, через который происходит вход в Crunchyroll. Видео при этом воспроизводится в **вашем** браузере, а не на сервере.

Сессии аккаунтов хранятся в зашифрованных cookies браузера; сервер держит пароли и токены в памяти только пока с ними работает. Ключи OAuth-приложений и ключ шифрования лежат в приватной конфигурации сервера. Прогресс просмотра и настройки сохраняются отдельно в каждом браузере.

## Дисклеймер

Это **неофициальный проект для личного использования**. Он никак не связан с Crunchyroll, Sony, Shikimori или MyAnimeList и не одобрен ими. Проект не обходит DRM и подписку — вы смотрите только то, что уже доступно вашему аккаунту. Crunchyroll может в любой момент что-то поменять у себя, и тогда вход или просмотр могут временно сломаться.
